# Frontend Clínica Rodriguez

Sistema de Gestión Clínica desarrollado con PHP y Bootstrap 5.

## Características

- Página pública informativa (Landing Page)
- Panel administrativo completo
- Dashboard con estadísticas
- Gestión de pacientes y médicos
- Sistema de citas médicas
- Historias clínicas
- Gestión de especialidades
- Reportes y estadísticas

## Tecnologías

- PHP 7.4+
- Bootstrap 5.3.2
- jQuery 3.7.1
- DataTables 1.13.7
- SweetAlert2 11.10.0
- Chart.js 4.4.0
- Bootstrap Icons 1.11.1

## Instalación

1. Clonar el repositorio en la carpeta de XAMPP
2. Configurar la base de datos en `vistas/modulos/config.php`
3. Acceder a `http://localhost/pe/`

## Rutas

- `/` - Página pública (Landing Page)
- `/login` - Acceso al panel administrativo
- `/dashboard` - Panel de control (requiere autenticación)
